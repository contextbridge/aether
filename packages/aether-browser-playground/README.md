# @aether-agent/browser-playground

A React + [assistant-ui](https://www.assistant-ui.com) test UI for [`@aether-agent/browser`](../aether-browser). It connects to a running `aether server` with the wasm client and renders the session: messages, streamed reasoning, tool calls with their diffs and sub-agents, the plan, context usage and elicitation forms. It also has a log of every raw client event.

## Run

1. Start a server built from this repository. It listens on `ws://127.0.0.1:8765`:

   ```bash
   aether server --cwd /path/to/project
   ```

2. Build the wasm client and start the dev server at <http://localhost:5173>:

   ```bash
   just playground
   ```

3. Press **Connect**. The playground resumes the server's live session and replays its history. If there is no live session, it starts one in the server's working directory.

`?url=ws://host:port` prefills a different server URL. To try the UI without a model, run the fake agent and open `?url=ws://127.0.0.1:8799/basic`, or `/elicitation`:

```bash
cargo run -p aether-acp-utils --example fake_agent_ws --features testing,websocket -- 8799
```

After changing `crates/acp-wasm` or `crates/acp-utils`, run `pnpm browser:build` again, and Vite reloads the page.

## Layout

- `src/aether/store.ts` keeps the `AetherClient` in a zustand store outside React. It connects only from the Connect button, because `aether server` accepts one client at a time. StrictMode's doubled effects, or a module that HMR replaced, would otherwise hold that slot.
- `src/aether/thread-messages.ts` projects each `Conversation` snapshot onto assistant-ui messages.
- `src/aether/runtime.ts` drives assistant-ui's `useExternalStoreRuntime` from those messages. Sending calls `AetherClient.prompt`, and stopping calls `cancel`.
- `src/components/aether/` holds the tool card (assistant-ui's `ToolFallback` slot), the elicitation dialog, the plan panel, the event log and the connection bar.
- `src/components/assistant-ui/` and `src/components/ui/` are generated by `shadcn add @assistant-ui/thread`. In this repository, `shadcn add` rewrites the `cn` import to an npm package named `cn`. Point it back at `@/lib/utils` and remove that dependency.

## Checks

```bash
pnpm playground:typecheck   # needs the wasm build (pnpm browser:build)
pnpm playground:test
```

`just wasm-test` runs both.
