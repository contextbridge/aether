title: Coding Tools
description: File operations, bash, search, web, and LSP-backed coding tools.
---

The `coding` server provides tools for reading and writing files, running shell commands, searching codebases, fetching web content, and using LSP-backed code intelligence. See [Tools](/aether/settings/mcp-servers/) for settings.

## Configuration

```json title=".aether/mcp.json"
{
  "servers": {
    "coding": {
      "type": "in-memory",
      "args": ["--rules-dir", ".aether/skills"]
    }
  }
}
```

Supported args:

| Arg                                                | Description                                                                     |
| -------------------------------------------------- | ------------------------------------------------------------------------------- |
| `--root-dir <path>`                                | Workspace root. Users don't need to set this as Aether sets this automatically. |
| `--rules-dir <path>`                               | Directory to load Rules from. Repeatable.                                       |
| `--permission-mode always-allow\|auto\|always-ask` | Approval behavior for destructive tools. Default is `always-allow`.               |
| `--disable-lsp`                                    | Do not attach LSP-backed coding tools.                                          |

Permission modes:

| Mode           | Behavior                                                                             |
| -------------- | ------------------------------------------------------------------------------------ |
| `always-allow` | Tool calls execute without eliciting approval. This is the default.                  |
| `auto`         | File writes auto-execute; destructive bash commands ask for approval.                |
| `always-ask`   | Every destructive tool — `write_file`, `edit_file`, `bash`, and `lsp_rename` — asks for approval; read-only tools are ungated. |

## File operations

| Tool         | Description                                          |
| ------------ | ---------------------------------------------------- |
| `read_file`  | Read a file with an optional line range (defaults to 2000 lines). |
| `write_file` | Write content to a file. Overwriting an existing file requires reading it with `read_file` first. |
| `edit_file`  | Exact string replacement, applied as an atomic batch (if one edit fails, no edits are applied). Requires reading the file with `read_file` first. |
| `list_files` | List directory contents with metadata.               |

## Search

| Tool   | Description                                                                                |
| ------ | ------------------------------------------------------------------------------------------ |
| `grep` | Regex search across files with context, file type filters, glob filters, and output modes. |
| `ast_grep` | Structural AST search using ast-grep patterns for functions, calls, and syntax shapes.      |
| `find` | Find files by glob pattern.                                                                |

## Bash

| Tool                   | Description                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| `bash`                 | Execute a shell command. Pass `timeout` to cap execution time (max 600000 ms), or `run_in_background` to run it as a background MCP task that returns its complete output at completion. Background mode requires the client to support MCP Tasks. |

Because `bash` spawns real subprocesses, it composes with [deferred (proxied) tools](/aether/settings/mcp-servers/#merging-and-deferred-tool-behavior) from other MCP servers via the `aether mcp` CLI — pipelines, redirects, and command substitution all work.

## Web

| Tool         | Description                                                            |
| ------------ | ---------------------------------------------------------------------- |
| `web_fetch`  | Fetch a URL, extract main article content, and convert it to Markdown. |
| `web_search` | Search the web via Brave Search API. Requires `BRAVE_SEARCH_API_KEY`.  |

## LSP tools inside `coding`

Unless `--disable-lsp` is set, Aether wires LSP-backed tools into the `coding` server.

| Tool                   | Description                                                               |
| ---------------------- | ------------------------------------------------------------------------- |
| `lsp_symbol`           | Definition, references, hover, implementation lookup, and call hierarchy. |
| `lsp_workspace_search` | Search for symbols across the workspace by name.                          |
| `lsp_document`         | Document symbol outline for a file.                                       |
| `lsp_check_errors`     | Compiler diagnostics without running a full build command.                |
| `lsp_rename`           | Rename a symbol across the workspace.                                     |
