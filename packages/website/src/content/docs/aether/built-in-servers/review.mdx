---
title: Review
---

Review MCP opens agent-authored artifacts for human review via its single tool, `review_artifact`. It supports:

- **Markdown** (`format: "markdown"`) opens in Aether's in-terminal Markdown review UI.
- **HTML** (`format: "html"`) opens in your browser with an annotation overlay for element-level comments.

Relative file paths resolve against the workspace root. Override the root with the `--root-dir <path>` arg (rarely needed — Aether sets it automatically):

```json
{
  "servers": {
    "review": { "type": "in-memory" }
  }
}
```

## Markdown

Submit Markdown inline or as a file path:

```json
{"format": "markdown", "source": {"type": "content", "content": "# Plan\n\nShip it."}}
{"format": "markdown", "source": {"type": "file", "path": "docs/aether/plans/feature.md"}}
```

## HTML

Submit HTML inline, as a file path, or as the URL of a web app already running on your machine. A file's relative URLs resolve against its directory, so sibling images, stylesheets and scripts load in the review:

```json
{"format": "html", "source": {"type": "content", "content": "<main><h1>Ship faster</h1></main>"}, "title": "Landing page"}
{"format": "html", "source": {"type": "file", "path": "site/index.html"}}
{"format": "html", "source": {"type": "url", "url": "http://localhost:5173/settings"}}
```

## Result

The tool blocks until the reviewer responds, then returns a `status`:

| Status      | Payload                                                                                  |
| ----------- | ---------------------------------------------------------------------------------------- |
| `approved`  | —                                                                                        |
| `feedback`  | `feedback` (text) plus optional `annotations` — `{ element, excerpt, comment }` per HTML element comment |
| `cancelled` | The reviewer dismissed the review without deciding                                        |
| `declined`  | The client refused the review request                                                    |

Markdown review uses MCP form elicitation and HTML review uses URL elicitation; clients that don't support the required elicitation mode receive an `ELICITATION_UNSUPPORTED` error.
